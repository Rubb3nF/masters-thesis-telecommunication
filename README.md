# Master's Thesis in Telecommunication

## Overview
This project focuses on Direction of Arrival (DOA) estimation using an optimized version of the MUSIC algorithm for large-scale antenna arrays.

A novel motion-aware MUSIC approach is proposed, which exploits temporal redundancy generated by the movement of a mobile platform to improve both estimation accuracy and computational efficiency.

## Contributions
- Motion-aware MUSIC algorithm for dynamic scenarios
- Improved accuracy leveraging temporal redundancy
- Reduced computational complexity for large arrays
- Robustness to coherent sources
- Source number estimation methods
- Mitigation of spurious peaks due to frequency mismatches

## Context
The method is designed for large antenna arrays mounted on moving platforms, where classical DOA techniques face scalability and robustness challenges.

## Repository structure
- `classes/` → core implementation (algorithms, models, utilities)
- `scripts/` → experiments, simulations, and evaluation scripts
